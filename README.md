# AURA | Atelier & Luxury Grooming Lounge Website

[![License: MIT](https://img.shields.io/badge/License-MIT-gold.svg)](LICENSE)
[![Status: Live](https://img.shields.io/badge/Status-Active-brightgreen.svg)]()

> A bespoke, ultra-luxury salon web application featuring live opening/closing status, dedicated haircut architecture gallery, beard sculpting showcase, transparent service menu, verified client reviews, and an interactive online reservation engine.

---

## 🌟 Key Features

### 1. 🕒 Live Opening & Closing Status Engine
- Real-time status indicator calculating **"OPEN NOW"** or **"CLOSED NOW"** based on system clock.
- Synchronized status badges across navigation header, hero pill, live hours card, weekly operating schedule table, footer, and mobile bottom bar.
- Interactive weekly schedule highlighting the current day.

### 2. ✂️ Haircut Styles Showcase (`#haircuts`)
- Filterable gallery tabs: *Fades & Tapers*, *Textured Crops*, *Classic & Executive*.
- Interactive detail pop-up overlay providing recommendations for face shapes, hair density, recommended styling products, and maintenance cycles.

### 3. 🧔 Beard Artistry & Grooming (`#beards`)
- Showcase featuring *Royal Sculpted Full Beard*, *Razor Lineup & Stubble Shaping*, and *Traditional Hot Towel Straight-Razor Shave*.

### 4. 💎 Services & Pricing Catalog (`#services`)
- Categorized menu displaying pricing, duration, and feature breakdown for Haircuts, Beard Care, and VIP Combination Packages.

### 5. 📸 Salon Ambiance Gallery (`#gallery`)
- High-resolution photorealistic visual assets showcasing the main sanctuary, barber workstations, beard studio, and whiskey lounge.

### 6. ⭐ Feedback & Verified Client Reviews (`#reviews`)
- Overall rating metric card (4.9/5 stars) with star percentage breakdown.
- Verified client review cards.
- Interactive modal allowing clients to post new reviews with a 1–5 star rating picker.

### 7. 📅 Multi-Step Booking Reservation Engine (`#booking`)
- Service selector pre-filled dynamically from any CTA.
- Barber / Specialist selector grid.
- Date picker & time slot selector.
- Instant reservation summary popup with booking reference code (e.g. `AURA-94821`).

- **Background Palette**: Obsidian Charcoal (`#0B0D10`), Deep Slate (`#141820`), Card Surface (`#1C212B`)

- **Typography**: *Cormorant Garamond* & *Playfair Display* (Serif headers) + *Plus Jakarta Sans* (Sans-serif UI)

## 🚀 Getting Started

Simply open `index.html` in any web browser or host on GitHub Pages / Vercel:

```bash
# Clone the repository
git clone https://github.com/amandumare2-rgb/aura-luxury-salon-website.git

# Navigate into directory
cd aura-luxury-salon-website

# Open in browser
open index.html
```
